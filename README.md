## 三个容易被忽略的成本

### 1. 续费价：Vultr 没有这一项，但比价要按内存档对齐

共享主机行业的常规做法是首期低价、续费翻倍。2026 年 9 月 Gizmodo 的一份 VPS 横向对照里，五家自管 VPS 的续费价是首期价的 1.7 到 2.9 倍：InMotion 的 4 vCPU 从 $13.99 涨到 $26.99，Hosting.com 的 8 GB 档从 $9.99 涨到 $29，HostGator Snappy 4000 从 $8.36 涨到 $18.70，DreamHost Stack 8 从 $9.49 涨到 $14.99。

### 2. 计费周期：低价往往来自长周期预付

InMotion 的 $13.99 基于 24 个月合约，Hosting.com 的 $9.99 基于 3 年期，DreamHost Stack 8 基于 2 年期。锁定期越长，单价压得越低，中途退出要付的代价也越高。

Vultr 是月付制，按小时累计、月度出账。开一台机器跑两小时然后删掉，只扣两小时的钱，不会因为标着"月付"就收整月，也不用签一年。代价是单价里没有长周期折扣，同样预算买到的配置会比长周期预付的少。

需要长期稳定跑的站点，长周期预付划算；项目周期不确定、随时可能推倒重来，按月付的退出成本更低。这一条比价格本身更影响最后的总花费。
